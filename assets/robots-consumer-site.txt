# BOT POLICY (three tiers):
#
# Tier 1 — Search engines: ALLOWED
#   Powers traditional search rankings AND AI search features (Google AI
#   Overviews, Bing Copilot). Best citation behaviour — always links back.
#
# Tier 2 — AI bots that cite sources: ALLOWED
#   Includes both retrieval bots (browse at query time) and training bots
#   from platforms that cite our sites in their answers. Our moat is data
#   freshness and quality, not secrecy — we want LLMs to have current
#   prices so citations are accurate and drive traffic back to our sites.
#
# Tier 3 — Bulk scrapers / low-citation platforms: BLOCKED
#   Bots that absorb content into datasets or models with no meaningful
#   attribution, or platforms too immature to evaluate. Revisited quarterly.
#
# REVIEW SCHEDULE: Review this file every quarter (Jan, Apr, Jul, Oct).
# Check for new bots, re-evaluate Tier 3 "wait and see" bots, and verify
# that Tier 2 platforms are still citing sources. Track in docs/TECH_DEBT.md.
#
# See docs/SECURITY_HARDENING.md for full context.
